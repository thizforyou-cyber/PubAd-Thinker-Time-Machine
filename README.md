# Thinker Time Machine — Public Administration NET/JRF

A standalone, browser-based study tool for exploring Public Administration thinkers, schools of thought, key works, major concepts, criticisms, and intellectual connections for UGC NET/JRF preparation.

## Features

- **Chronology:** browse thinkers by period and key contribution.
- **Schools of thought:** filter and compare thinkers across administrative theories and approaches.
- **Connections:** follow links between related thinkers and debates.
- **Thinker profiles:** review key works, contributions, concepts, criticisms, and related thinkers.
- **Search and filters:** find a thinker by name, work, concept, school, or period.
- **Responsive layout:** usable on desktop and mobile browsers.

## Run locally

Open `index.html` in a modern browser. The site is a static HTML/CSS/JavaScript app and does not require a build step.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)` folder, then save.
4. After GitHub Pages finishes deploying, use the published URL shown in that settings page.

## Study note

Use thinker profiles as revision prompts. Verify dates, editions, quotations, and specific attributions against your prescribed books and reliable academic sources. The database is a study aid, not a substitute for the official UGC syllabus or primary texts.
